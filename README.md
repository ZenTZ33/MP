# MP — Music Player

A sleek desktop music player built with **Electron**, featuring a dynamic UI that adapts its accent color to the currently playing track's album art.

![MP Screenshot](screenshot.png)

## ✨ Features

- 🎨 **Adaptive color theme** — the interface picks up the dominant color from each album cover
- 🎧 **Local music playback** — play your own audio files
- ⏯️ **Full playback controls** — play/pause, next/prev, shuffle, repeat
- 📊 **Progress bar** with seek support
- 🌙 **Dark, minimal UI** — easy on the eyes
- 🖥️ **Cross-platform** — runs on Windows, macOS, and Linux (via Electron)

## 🛠️ Tech Stack

- **Electron** — desktop app framework
- **JavaScript / HTML / CSS** — frontend
- **Node.js** — runtime

## 🚀 Getting Started (Development)

### Prerequisites

- [Node.js](https://nodejs.org/) (v16 or higher recommended)
- npm (comes with Node.js)

### Installation

1. Clone the repository:
   ```bash
   git clone https://github.com/ZenTZ33/MP.git
   cd MP
 
  2. Install dependencies:
     npm install
  3. Run the app in development mode:
     npm start
  📦 Building a Release
To build a distributable version (e.g. .exe for Windows):
     npm run build

     The output will be in the dist/ folder.
